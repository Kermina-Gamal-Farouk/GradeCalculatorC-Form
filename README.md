# Grade Calculator (C# Windows Forms)

A simple desktop app built with C# and Windows Forms (.NET Framework) that converts a student's score into a grade.

## Features
- Enter a score from 0 to 100.
- Shows the percentage and the grade.
- Shows an "Invalid Score" message for values above 100.
- Exit button closes the app.

## Grading scale
| Score  | Grade     |
|--------|-----------|
| 0-49   | Fail      |
| 50-64  | Pass      |
| 65-79  | Good      |
| 80-89  | Very Good |
| 90-100 | Excellent |
